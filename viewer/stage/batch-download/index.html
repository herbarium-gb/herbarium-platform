Batch Download

  1. Search our database and export the results as a TSV file.
  2. Download one of the scripts below.
  3. Run the script with your TSV file. It downloads the images and skips files already downloaded, so you can stop and resume anytime.

    RStudio: Set ids_file to your TSV file and run the script.
    R: Rscript batch_download.R export.tsv --base-url https://botmus.gu.se
    Python: python3 batch_download.py export.tsv --base-url https://botmus.gu.se
